# 🎬 SanekBot

Асинхронный Telegram-бот для автоматической прожарки авторов видео-кружков (video notes) в групповых чатах. 

> **Предыстория:** Проект родился в момент, когда я окончательно устал слушать 20-секундные видео-кружки от друзей ради двух слов, которые можно было набрать текстом за 2 секунды. Бот создан для автоматического восстановления текстовой дисциплины в чате.

Бот скачивает видеосообщение, транскрибирует аудио через Whisper и генерирует контекстный ответ с помощью Llama 3.3, высмеивая сказанные слова, длительность записи и паузы.

---

## 🛠️ Стек технологий

* **Язык:** Python 3.11+
* **Фреймворк:** `aiogram 3.x` (Asyncio)
* **AI & STT:** Groq API (`whisper-large-v3-turbo` + `llama-3.3-70b-versatile`)
* **DevOps:** Docker, Docker Compose, Linux (Ubuntu VPS)
* **Архитектура:** Модульная (разделение конфигов, утилит очистки и основной хэндлер-логики)

---

## ⚡ Архитектура и пайплайн работы

1. **Обработка сообщения:** Хэндлер перехватывает `video_note`, проверяет права отправителя по `TARGET_USER_ID` и скачивает `.mp4` файл.
2. **Транскрибация речи:** Аудиопоток отправляется в Groq Whisper API (`whisper-large-v3-turbo`) с указанием русского языка и контекстного промпта.
3. **Санитайзинг STT:** Модуль `cleaners.py` отсекает китайские/латинские символы и фильтрует галлюцинации Whisper на тишину/шум (заглушки типа "продолжение следует", "субтитры" и т.д.).
4. **Prompt Engineering:** Формируется динамический промпт для Llama 3.3: подмешиваются метаданные (имя, длительность с коррекцией оффсета TG API), очищенный текст речи, случайно выбранный вектор прожарки и Few-Shot пример пасты.
5. **Генерация и cleanup:** Модель выдает ответ, бот отправляет его в тред и удаляет временный файл видеосообщения с диска.

## ⚙️ Конфигурация (`.env`)

Логика фильтрации участников настраивается через переменную `TARGET_USER_ID`:

* **`TARGET_USER_ID=0`** — Режим «Резать всех». Бот будет реагировать на видео-кружки **абсолютно всех пользователей** в чате.
* **`TARGET_USER_ID=12345678,98765432`** — Белый список (Whitelisting). Бот игнорирует сообщения остальных людей и прожаривает **только указанные Telegram ID** (можно перечислять через запятую без пробелов). Useful-фича, если нужно натравить бота на конкретных корешей в группе.

Пример итогового `.env`:
```env
BOT_TOKEN=your_telegram_bot_token
GROQ_API_KEY=your_groq_api_key
TARGET_USER_ID=0
```

## 🎭 Кастомизация промптов и паст

Характер бота, его агрессия, сленг и локальные шутки полностью изолированы от кода и редактируются в файле `config/prompts.py`:

* **`SYSTEM_PROMPT`** — задаёт роль, правила генерации и степень токсичности ответа.
* **`ROAST_STYLES`** — вектор удара (акцент на тупости слов, заиканиях, режиме блогера и т.д.), который случайно выбирается под каждый кружок.
* **`MOCKERY_PASTAS`** — база ваших локальных мемов и паст. Бот подмешивает их вайб и ритмику в ответ как Few-Shot примеры.
